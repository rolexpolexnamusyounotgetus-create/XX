# Concept reference copies

Read-only copies of the three homepage concepts the judges scored on Mon, Nov 9, 2026, kept so
page builders can look up where a pattern came from. The site does not load anything from here.

| Folder | Concept | Verdict (BRIEF §0) |
|---|---|---|
| `A/` | "Group Chat" (`index.html`, `a.css`, `a.js`, `RATIONALE.md`) | **Winner.** Refactored into the token and component system in `assets/css/` and `assets/js/ui.js` (F0). |
| `B/` | Golden hour editorial (`index.html`, `RATIONALE.md`, its review scripts in `tools/`) | Grafts: the golden-hour photo grade (`.photo--golden`) and duotone event covers (`.photo--duo`). |
| `C/` | Organizer Arcade (`index.html`, `c.css`, `c.js`, `c-data.js`, `RATIONALE.md`) | Grafts: metric-matched fallback `@font-face` (re-measured for our fonts in `assets/css/tokens.css`), `aria-invalid`, content-as-data. |

The concepts' screenshots and `media/` folders (demo clips, posters) are left out on purpose: the
clips already live in `assets/video/`, and the screenshots are several MB each.

Do not copy copy (words) from these files without checking BRIEF §0's kill list: the chat thread,
"Join the chat", the "¡Vamos!" sticker, `value="Sam"`, hard-coded `youngsemdems.com` links, "Every
Florida mail ballot request runs out Dec 31", candidate names, C's XP and levels, B's rooftop photo
and magazine folio chrome are all out.
