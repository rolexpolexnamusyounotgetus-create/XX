official links only

Sorted by deadline. Voting links go straight to the official county and state sites.

  1. 52days left

    Real deadline 52 days left until December 31, 2026.

    Every Florida mail ballot request runs out Dec 31.

    That includes yours if you voted by mail this year. Request again so you're covered for the 2027 city elections and for 2028.

    Renew on voteseminole.gov

    Not sure when 2027 requests open? The Supervisor of Elections can tell you: 407-585-8683. F.S. 101.62

  2. New rule · Jan 1, 2027

    Student ID? It stops counting at the polls.

    Starting Jan 1, 2027, Florida stops accepting student IDs at the polls (it's being challenged in court). Bring a driver's license, state ID or passport, and check voteseminole.gov before you go.

    UCF and Seminole State, this one's for you.
